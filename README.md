**ANCHOR** (**A**ccountability, **N**urture, **C**larity, & **H**onest **O**pen **R**econnection) is an evidence-based, clinical-grade relational trust reconstruction engine designed for romantic couples navigating the aftermath of severe relationship betrayal, chronic dishonesty, or infidelity. 

Unlike conventional couple messaging apps or punitive tracking software, ANCHOR operationalizes gold-standard couples therapy protocols—including **Cognitive Behavioral Couple Therapy (CBCT)**, **Emotionally Focused Therapy (EFT)**, the **Gottman Method**, and **Operant Conditioning**—into a secure, structured digital environment that prevents re-traumatization, halts trickle-truth cycles, de-escalates physiological flooding, and converts behavioral reliability into measurable data.

## 🧠 Clinical Foundations & Evidence Base

ANCHOR is built upon validated psychological and marital therapy methodologies:

```
                  ┌─────────────────────────────────────────────────────────┐
                  │          ANCHOR RELATIONAL TRUST ENGINE                 │
                  └─────────────────────────────────────────────────────────┘
                                               │
         ┌───────────────────┬─────────────────┴─────────────────┬───────────────────┐
         ▼                   ▼                                   ▼                   ▼
┌─────────────────┐ ┌─────────────────┐                 ┌─────────────────┐ ┌─────────────────┐
│  CBCT (Baucom)  │ │   EFT & AIRM    │                 │ Gottman Method  │ │Operant Learning │
│ 3-Stage Model:  │ │(Sue Johnson):   │                 │ (Sound House):  │ │(Truth-Default): │
│ Impact → Meaning│ │Attachment Injury│                 │ >100 BPM DPA    │ │Micro-actions,   │
│ → Redefinition  │ │Resolution &     │                 │ Lockouts, 4-7-8 │ │BCI Score, Proof │
│ (No Trickle)    │ │Blamer-Softening │                 │ Somatic Pacing  │ │Verification     │
└─────────────────┘ └─────────────────┘                 └─────────────────┘ └─────────────────┘
```

1. **Cognitive Behavioral Couple Therapy (CBCT — Baucom et al.)**:
   - Structured 3-stage model: *Impact / Crisis Stabilization* $\rightarrow$ *Meaning-Making & Comprehensive Factual Disclosure* $\rightarrow$ *Relational Redefinition*.
   - Replaces damaging "trickle truth" (piecemeal confessions over months) with a single, comprehensive, structured disclosure process.

2. **Emotionally Focused Therapy (EFT — Dr. Sue Johnson)**:
   - Implements the **Attachment Injury Resolution Model (AIRM)**.
   - Guides the participating partner through non-defensive accountability, emotional validation, and blamer-softening sequences.

3. **Gottman Method Couple Therapy (Drs. John & Julie Gottman)**:
   - **Diffuse Physiological Arousal (DPA) Management**: Automatic detection and enforcement of mandatory 20-minute timeout lockouts when heart rate exceeds 100 BPM.
   - **Four Horsemen Elimination**: Real-time interception of Criticism, Contempt, Defensiveness, and Stonewalling.
   - **Atonement, Attunement, and Attachment Framework**.

4. **Integrative Behavioral Couple Therapy (IBCT — Jacobson & Christensen)**:
   - Promotes emotional acceptance, empathic joining around the problem, and unified detachment from toxic communication cycles.

5. **Operant Conditioning & Truth-Default Theory (Levine)**:
   - Re-establishes relational predictive validity through repeated, verifiable, small-scale positive commitments rather than empty verbal promises.

## 🛠 System Architecture & Core Modules

### 1. Safety Triage & Emergency Panic Disconnect
- **Clinical Contraindication Gatekeeper**: Evaluates couples for Intimate Partner Violence (IPV), coercive control, ongoing active deception, and unmanaged addiction before clinical trust exercises can proceed.
- **Emergency Panic Button**: Instantly clears all active state from the client, terminates the session, and presents immediate crisis assistance lifelines (988 Suicide & Crisis Lifeline, National Domestic Violence Hotline: 1-800-799-SAFE).

### 2. Multi-Partner Lobby & Real-Time Sync Engine
- **Session Code Pairing (`ANCHOR-XXXX`)**: Couples pair their devices using an encrypted room code.
- **Multi-Tab / Multi-Device Synchronization**: Powered by browser `BroadcastChannel` API and persistent local state synchronization for latency-free dual-client operation.
- **Live Presence & Dual-Readiness**: Tracks partner online status and mutual readiness flags before unlocking shared clinical stages.

### 3. 8-Phase Dynamic Clinical State Engine
Enforces a stage-gated, clinical recovery pathway where advanced modules unlock only after preceding clinical gates are verified:
- **Phase 1: Stabilization & Crisis Management** — Impact containment, boundary establishment, zero active deceit.
- **Phase 2: Truth Reconstruction** — Dual-lock chronological timeline disclosure and diagnostic inquiries.
- **Phase 3: Emotional Processing** — Attachment injury resolution and non-defensive attunement practice.
- **Phase 4: Behavioral Reconditioning** — Daily micro-commitments and Behavioral Consistency Index (BCI) tracking.
- **Phase 5: Communication Repair** — Gottman Sound Relationship House exercises and de-escalated dialogue.
- **Phase 6: Shared Meaning & Connection** — Relational redefinition, shared values, and positive dyadic rituals.
- **Phase 7: Vulnerability & Intimacy** — Sensate focus guidelines and consensual emotional reconnection.
- **Phase 8: Long-Term Maintenance & Sunset** — Decommissioning surveillance scaffolding and solidifying permanent trust.

### 4. Module 1: Asynchronous Dual-Lock Timeline & Disclosure Vault (CBCT)
- **Solo Drafting with Real-Time NLP Guardrails**:
  - **PISD Prevention**: Detects and intercepts intrusive, sexually graphic physical descriptions that induce Post-Infidelity Stress Disorder (PISD) flashbacks in the betrayed partner.
  - **Blame-Shifting Interception**: Flags rationalizations, excuses, or victim-blaming statements before submission.
- **Dual-Lock Vault Protocol**: Disclosures remain encrypted and hidden until both partners enter the session simultaneously and explicitly unlock the vault together.
- **Diagnostic Inquiry Queue**: Structured Q&A queue allowing the injured partner to ask specific diagnostic questions (timeline gaps, financial scope, boundary confirmation) with clinical categorization.

### 5. Module 2: Biometric Flooding Alert & Smart De-escalation (Gottman)
- **Physiological Telemetry Simulation**: Real-time heart rate (BPM) and Heart Rate Variability (HRV) monitoring.
- **Gottman 20-Minute Lockout**: When heart rate surpasses 100 BPM or acute flooding is flagged, the system initiates a strict 20-minute de-escalation lockout.
- **Interactive 4-7-8 Somatic Visualizer**: Guided breathing pacer (4s Inhale, 7s Hold, 8s Exhale) to actively stimulate vagal tone and restore parasympathetic nervous system regulation.
- **Dual Regulation Sign-Off**: Both partners must independently confirm their physiological regulation before conversation tools re-enable.

### 6. Module 3: Behavioral Reliability Dashboard & Consistency Index (BCI)
- **Micro-Commitment Execution**: Daily micro-agreements across 5 critical domains:
  - *Communication*, *Schedule Integrity*, *Financial Clarity*, *Transparency*, and *Relational Care*.
- **Objective Proof Verification**: Supports timestamp logs, location check-ins, receipt uploads, and mutual partner verification.
- **Behavioral Consistency Index (BCI)**: Real-time mathematical scoring calculated over 30, 60, and 90-day rolling windows:
  $$\text{BCI} = \left( \frac{\text{Verified Completed Commitments}}{\text{Total Assigned Commitments}} \right) \times 100$$

### 7. Module 4: Real-Time NLP Non-Defensive Attunement Coach (EFT/AIRM)
- **On-the-Fly Defensiveness Interception**: Scans draft messages in real-time for:
  - Blame-Shifting, Minimization, Gaslighting, Counter-Accusations, and Stonewalling.
- **1-Click EFT Reframing Engine**: Translates defensive knee-jerk reactions into vulnerable, emotionally attuned, and validating statements grounded in Sue Johnson's AIRM principles.
- **Attunement Score (0–100)**: Real-time scoring reflecting the empathetic depth and vulnerability of communication.

### 8. Module 5: Consensual Transparency Scaffolding & Sunset Manager
- **Non-Coercive Temporary Scaffolding**: Voluntary, dignity-preserving check-ins (calendar, location, finances, digital activity).
- **Automated 30/60-Day Sunset Clause**: Surveillance and monitoring are clinically recognized as temporary crutches that hinder long-term organic trust if maintained indefinitely.
- **Mutual Decommissioning Sign-Off**: Once a couple maintains >95% BCI over 60 consecutive days, the system triggers a formal sunset protocol to mutually decommission and delete tracking feeds.

### 9. Psychometrics & Longitudinal Tracking Suite
- **Standardized Clinical Inventories**:
  - **Dyadic Trust Scale (DTS)** (Rempel, Holmes, & Zanna)
  - **Revised Dyadic Adjustment Scale (RDAS)** (Busby et al.)
  - **Perceived Emotional Safety Index**
- **Longitudinal Trend Analytics**: 14-day interval assessment graph visualizing trajectory curves against clinical benchmarks.

## 👥 Partner Roles & Dual-Client Workflow

ANCHOR accommodates multiple user perspectives seamlessly:

| Role | Codename | Purpose & Permissions |
| :--- | :--- | :--- |
| **Partner A** | *Participating / Disclosing Partner* | Drafts factual disclosures, completes daily micro-commitments, submits voluntary transparency logs, practices EFT reframing. |
| **Partner B** | *Injured / Betrayed Partner* | Submits diagnostic questions, verifies micro-commitment proofs, acknowledges disclosures at own pace, tracks emotional safety. |
| **Supervisor** | *Clinician / Facilitator* | Read-only oversight of phase progression, psychometric trajectories, and adherence metrics. |

### Dual-Split Client Mode
To facilitate clinician testing, solo rehearsal, or shared-screen therapy sessions, ANCHOR includes a **Dual-Client View** button in the header that splits the screen into synchronized side-by-side viewports for Partner A and Partner B in real time.

## 🔒 Security, Privacy & Anti-Surveillance Ethics

- **Zero-Knowledge Architecture**: All relational state, disclosures, and biometrics reside client-side in browser storage.
- **Anti-Surveillance Protocol**: The application explicitly prohibits covert monitoring, keylogging, or unilateral spyware. Transparency is strictly voluntary, mutual, and subject to automated sunset decommissioning.
- **Instant Data Portability & Purge**: Export entire state backups as encrypted JSON files, or permanently wipe all session records via the emergency disconnect trigger.

## 🚀 Getting Started & Installation

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher

### Step 1: Install Dependencies (one-time)
Run this command once when setting up the project locally:
```powershell
npm install
```

### Step 2: Start Development Server (every session)
Run this command every time you begin a development session:
```powershell
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### Step 3: Production Build (one-time / deployment)
To compile the production-ready optimized bundle:
```powershell
npm run build
```

### Step 4: Preview Production Build (optional)
```powershell
npm run preview
```
